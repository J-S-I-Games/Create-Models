# Create Models

**Create Models** es una herramienta web desarrollada por **J-S-I Games** para crear modelos 3D directamente desde el navegador.

## Código fuente:

Este repositorio es público porque quiero que cualquiera pueda ver cómo está desarrollado el proyecto y aprender de su código.

Podés explorarlo y estudiar cómo funciona, pero **que el código sea público no significa que puedas apropiarte de mi trabajo y presentarlo como tuyo**.

- ✅ Podés consultar el código fuente y aprender de él.
- ❌ No te atribuyas la autoría del proyecto.
- ❌ No publiques una copia como si fuera una creación propia.
- ❌ No elimines los créditos para hacer pasar el trabajo por tuyo.

En resumen: **mirar, aprender e inspirarse está bien; robar el trabajo ajeno, no.** No hace falta hacerse el vivo.
